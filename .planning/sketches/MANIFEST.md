# Sketch Manifest

## Design Direction
A local-first trading journal where AI feels native to the workspace: it maintains a focused conversation, asks for missing facts, and progressively prepares a typed draft that the user reviews in the existing UI before anything is saved.

## Reference Points
- Existing Trade Journal cards, inline AI recap trigger, and privacy-respecting BYO-key model.
