Use an active wait loop only if explicitly requested.

The conservative serial phase chain follows the normative plan despite generic orchestration advice favoring shallower dependency graphs.

No push, PR, publication or feature→main merge. For a failed gate preserve branch and report the exact blocker. For an execution-host mismatch or unavailable OMP/native orchestration, do not silently fall back into Codex or a shared checkout.

Final feature acceptance requires every phase and both slices plus release gates; a worker success message is never sufficient on its own.
